# 🐾 Ubby — My Pixel Pet

Bem-vindo ao repositório do **Ubby**! Este é um projeto de bichinho virtual em Pixel Art, focado em personalização e persistência de dados. 

O Ubby nasceu do desejo de unir meu amor por arte digital com os conceitos que estou aprendendo na faculdade de **Análise e Desenvolvimento de Sistemas**.

## ✨ O que é o Ubby?
Ubby é um simulador multiplataforma (Android/PC) onde você pode adotar, cuidar e personalizar seu próprio amigo pixelado. O projeto foca em:
- **Personalização Dinâmica:** Troca de cores e acessórios.
- **Lógica de Estados:** Ciclos de fome, sono e felicidade.
- **Portabilidade:** Experiência consistente em diferentes dispositivos.

## 🛠️ Tecnologias
- **Engine:** Godot 4.5
- **Linguagem:** GDScript (POO)
- **Artes:** Piskel (Pixel arts 64x64)
- **Versionamento:** Git & GitHub (seguindo padrões de ADS)

## 🗂️ Organização do Projeto
Para manter a "saúde" do código e facilitar a manutenção, o projeto segue esta estrutura:
- `/assets`: Todos os sprites, fontes e efeitos sonoros.
- `/docs`: Documentação técnica e requisitos (confira o [DOCS.md](./DOCS.md)).
- `/src`: Cenas e scripts lógicos da Godot.
